# 週報 → 出席人員表（國會版）產生器

## 目的

**輸入**：立法院每週的會議週報，例如 [`第11屆第6會期會議週報(2026.11.30~2026.12.4).doc`](第11屆第6會期會議週報(2026.11.30~2026.12.4).doc)（「立法院第11屆第6會期會議情形分週預報表」）。

**輸出**：本處用的「立法院各委員會審查日程及出席人員表（國會版）」，例如 [`1151130-1204出席人員(國會版).doc`](1151130-1204出席人員(國會版).doc)。列出特種基金、信託基金、財團法人的預算；可能要出席的議程（所有法案、公聽會、專題報告、業務報告、考察）另起一列、整列黃底、本處代表填「待確認」，由人工判斷要不要出席。

**網址：** https://cormort.github.io/ly-delegate/

## 範例

repo 裡附了一份週報 [`第11屆第6會期會議週報(2026.11.30~2026.12.4).doc`](第11屆第6會期會議週報(2026.11.30~2026.12.4).doc)。下載後丟進頁面，會產出 17 列：
- 10 列基金與財團法人預算審查（財政、經濟、交通、內政、社福及衛環、外交及國防、司法及法制）。
- 7 列黃底「可能要出席」：司法及法制的公務人員考績法修正草案、財政的金融資安專題報告、內政的業務報告，以及教育及文化、社福及衛環、外交及國防、司法及法制的考察。

對照用的人工版本是 [`1151130-1204出席人員(國會版).doc`](1151130-1204出席人員(國會版).doc)（只有預算列）。預算列和它有兩處不同：
- 財政委員會 12/2、12/3 的會議室不同（群賢樓9樓大禮堂、紅樓302會議室），產生器兩個都列，人工版只列一個。
- 司法及法制委員會 12/2 的主持人，週報寫陳委員昭姿，產生器照週報，人工版寫成王委員義川。

## 怎麼用

1. 打開上面的網址（或直接用瀏覽器開 `index.html`）。
2. 把週報 `.doc` 拖進虛線框，或點框裡的「點此選擇檔案」，例如 `第11屆第6會期會議週報(2026.11.30~2026.12.4).doc`。
3. 畫面會出現整理好的表格。表格可以直接點進去改，例如填「本處代表」、修案由文字。
4. 按「下載 .doc」，檔名會自動帶日期，例如 `1151130-1204出席人員(國會版).doc`，用 Word 開啟即可。

檔案只在你的瀏覽器裡處理，不會上傳到任何地方。

## 會挑出哪些議程

| 類別 | 判斷方式 | 呈現 |
| --- | --- | --- |
| 特種基金、信託基金、國營事業 | 案由含「附屬單位預算」「特種基金」，或點名[基金清單](https://cormort.github.io/excel_merge/fund-config.json)裡的基金且含「預算」（歲入、凍結案除外） | 一般列 |
| 財團法人 | 案由含「預算書」 | 一般列 |
| 可能要出席：法案、公聽會、專題報告、業務報告、考察 | 案由含「草案」「擬具」「函請審議」「公聽會」「專題報告」「業務報告」「考察」，或以「邀請」開頭（邀請首長報告）。不限本處主管；公聽會、各種報告和考察也可能要出席，所以跟法案同樣處理。是否與本處有關，會議通知看不出來，由人工判斷 | **整列黃底**，另起一列，本處代表填「待確認」 |
| 不列 | 公務預算（單位預算、收支部分）、歲入、凍結案等其他預算案；召委選舉、請願案、人事同意權審查、全院委員會；院會；放假日 | — |

- 同一委員會、同樣案由在不同天開會，會併成一列（例如「12月02日 / 12月03日 (星期三/四)」）；會議室不同時兩個都列。
- 同一場會議如果有預算案也有法案／公聽會／報告／考察，會拆成兩列：預算列一般，另一列黃底待確認。
- 舊格式週報把多案寫在同一段「一、…二、…」，會自動拆開；跨頁斷開的會議會接回同一列。
- 開會事由後面的【…】附註會轉成【僅詢答】【處理】【詢答及處理】標記。

## 限制

- 只吃 Word 97-2003 的 `.doc`。拿到 `.docx` 請先在 Word「另存新檔」成 `.doc`。
- 週報表格要維持 8 欄（月／日、星期、時間、單位、輪值召委、開會事由、地點、聯席委員會）；格式變了頁面會報錯，不會產出錯的表。
- 下載的 `.doc` 實際上是 Word 可直接開啟的 HTML；要正式存檔可在 Word 裡「另存新檔」成 `.docx`。
- 基金清單從 GitHub 線上載入；網路擋掉時頁面會顯示「載不到」，只用關鍵字判斷。
- 已用 [ly.gov.tw 會議週報查詢](https://www.ly.gov.tw/Pages/List.aspx?nodeid=4808) 上 115 年 7–11 月共 12 週的週報測過，都能解析。
- 產出後請人工核對一次再送出。
