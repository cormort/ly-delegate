# 週報 → 出席人員表（國會版）產生器

把立法院議事處的「會議情形分週預報表」（週報 `.doc`）轉成本處用的「各委員會審查日程及出席人員表（國會版）」。

**網址：** https://cormort.github.io/ly-delegate/

## 怎麼用

1. 打開上面的網址（或直接用瀏覽器開 `index.html`）。
2. 按「選擇檔案」，選週報 `.doc`，例如 `第11屆第6會期會議週報(2026.11.30~2026.12.4).doc`。
3. 畫面會出現整理好的表格。表格可以直接點進去改，例如填「本處代表」、修案由文字。
4. 按「下載 .doc」，檔名會自動帶日期，例如 `1151130-1204出席人員(國會版).doc`，用 Word 開啟即可。

檔案只在你的瀏覽器裡處理，不會上傳到任何地方。

## 會挑出哪些議程

| 類別 | 判斷方式 | 呈現 |
| --- | --- | --- |
| 特種基金、信託基金、國營事業 | 案由含「附屬單位預算」「特種基金」，或點名[基金清單](https://cormort.github.io/excel_merge/fund-config.json)裡的基金且含「預算」（歲入、凍結案除外） | 一般列 |
| 財團法人 | 案由含「預算書」 | 一般列 |
| 本處主管法案 | 案由含清單裡的法律名稱（預算法、決算法、會計法、統計法、財政紀律法…） | **整列黃底**，與同場預算案分開成一列 |

- 法案清單在頁面上的「本處法案」可以展開修改（一行一部法律），重新選一次檔案就會套用。清單取自 ly-dashboard 中主管機關為行政院主計總處的法律。
- 同一委員會、同樣案由在不同天開會，會併成一列（例如「12月02日 / 12月03日 (星期三/四)」）；會議室不同時兩個都列。
- 開會事由後面的【…】附註會轉成【僅詢答】【處理】【詢答及處理】標記。

## 限制

- 只吃 Word 97-2003 的 `.doc`。拿到 `.docx` 請先在 Word「另存新檔」成 `.doc`。
- 週報表格要維持 8 欄（月／日、星期、時間、單位、輪值召委、開會事由、地點、聯席委員會）；格式變了頁面會報錯，不會產出錯的表。
- 下載的 `.doc` 實際上是 Word 可直接開啟的 HTML；要正式存檔可在 Word 裡「另存新檔」成 `.docx`。
- 基金清單從 GitHub 線上載入；網路擋掉時頁面會顯示「載不到」，只用關鍵字判斷。
- 產出後請人工核對一次再送出。
